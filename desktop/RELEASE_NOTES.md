JUAI 0.1.1：新增版本检查与升级资料保护，修复新版 Chrome / Edge 的浏览器连接。

## 已安装 0.1.0 的用户

0.1.0 本身没有更新器，请先下载对应系统的 0.1.1，退出旧版后覆盖安装一次。无需卸载或清空工作区。安装后可在「帮助 → 检查更新」检查后续版本，也可开启自动检查、选择正式版或包含预览版的通道。

新版本首次启动会在数据库迁移前，自动完整备份现有工作区到相邻的 `JapanGradWorkspace.backups` 文件夹。备份失败会停止启动，资料较多时请耐心等待。相同版本再次启动不重复备份。

## 本次改动

- 启动后自动检查 GitHub Releases，并提供手动检查、下载进度、取消下载和 SHA-256 校验。
- 用户确认后，Windows 打开 MSI 覆盖安装向导；Mac 打开 DMG，由用户替换应用。当前仍需安装确认，不是静默更新。
- 数据库通过 SQLite backup API 备份，保留已提交的 WAL 数据；原文件、笔记、资料索引一起备份。高于支持版本的数据库会拒绝打开。
- 浏览器连接兼容 Chrome 的 WebSocket-only 调试模式，不再因为 `/json/version` 返回 404 而误判未开启。
- 区分「已检测到」与「已授权连接」，连接时提示在 Chrome / Edge 点击允许，重复检查复用已授权连接。

## 下载与安装

| 系统 | 安装包 | 安装方式 |
| --- | --- | --- |
| macOS 14 及以上，Apple Silicon（M 系列） | `JUAI-0.1.1-mac-arm64.dmg` | 打开 DMG，将 JUAI 拖入 Applications 并替换。 |
| macOS 14 及以上，Intel | `JUAI-0.1.1-mac-x64.dmg` | 打开 DMG，将 JUAI 拖入 Applications 并替换。 |
| Windows 10 / 11，64 位 Intel / AMD | `JUAI-0.1.1-win-x64.msi` | 双击安装向导，覆盖安装后从开始菜单或桌面启动 JUAI。 |

安装包已内置运行时，无需安装 Node.js、pnpm 或开发环境。Windows ARM 和 Linux 暂未提供原生安装包。

这是未签名的开源预览版，尚未配置 Apple Developer ID 公证和 Windows 代码签名。macOS 首次打开可能需要在「系统设置 → 隐私与安全性」确认「仍要打开」；Windows 可能提示未知发布者。可先对照 `SHA256SUMS.txt` 核验下载文件。

## 工作台功能

- 大学、研究科、专攻、研究室和老师资料整理，校徽、地域、QS 与留学预算对比。
- 输入官网网址，通过本地 Agent 或自带 API 提取资料，核对后建档；支持 DeepSeek 配置。
- 募集要项提取草稿、历年考试对比与批量录入。
- 想考研究室、教授联络看板、材料待办、报考时间线与自选属性 Excel 导出。
- 论文和资料归档、PDF 阅读、标注笔记与文档问答。
- 动态进入页、申请总览、深色模式与独立桌面窗口。

## 本地资料与已知限制

- 默认资料位于当前用户的 `Documents/JapanGradWorkspace`（文稿 / 文档目录）。已有便携版使用相同目录，可继续读取；升级或卸载不会主动删除该目录，建议定期备份。
- 资料在本机保存，安装包不包含开发者资料、API 密钥或登录凭据。AI 功能需要用户配置本地 Agent 或自己的模型 API。
- macOS 内置日语 / 英语 Vision OCR。Windows 的扫描件 OCR 需要另装支持 `jpn` 的 Tesseract 并加入 PATH，或使用支持图片的模型；文字版 PDF / DOCX 解析不受此限制。
- 本地 Agent、用户 Chrome 连接等能力依赖本机已安装和配置的对应程序。
- 更新需要用户确认安装；自动检查和下载不会替代系统安装授权。AI 提取的考试时间、资格和材料仍需核对官网原文。

反馈问题时请附系统版本和操作步骤；应用菜单「文件 → 打开日志文件夹」可定位启动日志，分享日志前请检查私人信息。
