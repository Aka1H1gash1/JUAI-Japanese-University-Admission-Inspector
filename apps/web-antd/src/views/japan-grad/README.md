# JapanGrad 本地浏览器工作台

当前流程：大学清单与横向对比 → 研究科 → 专攻 → 研究室 → 老师；专攻下管理募集要项、过去问和对应答案，老师下管理论文和邮件往来。

## 界面与主题

界面使用统一的字体、间距、圆角和语义配色。桌面侧边栏提供大学清单、修考之路、已有大学和当前研究科 / 专攻 / 研究室的快捷入口；手机通过顶部菜单打开导航。右上角主题菜单支持浅色、深色与跟随系统，选择保存在当前浏览器中。弹窗、抽屉、上传、考试表和邮件与页面共享主题。

点击侧边栏或页脚「本地工作区」可查看资料保存位置并复制路径。界面图标使用已安装的 Lucide 本地组件，无需访问 CDN；老师卡片使用姓名缩写作为身份标记。支持键盘跳转到主要内容，选择框提供内部输入标签与展开状态，并响应减少动态效果偏好。

设计审查、改版前后预览及 Lighthouse 报告见工作区 `design/REDESIGN.md`。所有设计验证数据都在独立的临时工作区中。

大学清单使用紧凑卡片，点击卡片任意普通区域进入大学详情，不再单独显示「查看研究科」按钮；对比勾选独立操作。老师卡片同样整卡进入独立详情页，心仪和编辑按钮独立操作。老师详情地址包含大学 / 研究科 / 专攻 / 研究室 / 老师 ID，旧老师链接继续可用，验证完整归属关系，支持刷新、直接打开、返回所属研究室；资料、论文库与邮件往来的当前栏目保存在 URL 查询参数中。

所有工作台页面顶部提供「返回上一级」，按大学 / 研究科 / 专攻 / 研究室 / 老师层级返回，直接打开链接也可用；修考之路返回大学清单，大学清单作为根页面禁用返回按钮。旧老师链接能识别所属研究室并返回。

## 研究室与修考之路

专攻详情以研究室为入口，每个研究室可记录名称、日文名称、研究方向、官网、个人备注，以及额外考试 / 出愿要求。整张卡片进入研究室详情，老师在研究室内单独维护；老师的论文与邮件仍属于原老师。编辑老师时可调整到同一专攻下的其他研究室，身份 ID、论文和邮件不变。

在「修考之路」点击「新增研究室」，可直接搜索所有已整理的研究室，按大学筛选并一次勾选多个加入；支持全选当前结果，已加入的目标明确标记且不可重复添加，取消选择窗口不修改资料，确认时一次保存整批选择。搜索或筛选切换不会丢失已选项。也可在研究室卡片或详情点击「想考」，目标会出现在侧边栏的「修考之路」。此处支持按研究室、大学、方向、地域、老师搜索，勾选 2–6 个目标横向对比。对比可选具体考试年份或各专攻最新已记录年份，同一年的不同批次分别显示。年度开销 = 年度学费 + 12 ×（月房租 + 月生活费），不含一次性入学金；首年和两年总费用另列。缺失费用显示已知小计与待补充项。

「导出 Excel」导出当前搜索结果，「导出所选」或对比窗口内的按钮只导出已选研究室。工作簿包含「研究室对比」「历年考试」「材料与待办」「字段说明」，对比表包含研究方向、老师、QS / 榜单年份、地域 / 都道府县、年度 / 首年 / 两年费用、费用明细、寮信息、考试科目与各阶段时间、出愿材料、研究室特殊要求、官网、备注等。历年考试表包含导出目标所属专攻的所有记录，不受对比年份筛选影响。冻结表头与前两列，支持筛选、换行；费用输入为数值，费用合计为带缓存值的可重算公式，输入缺项时相应总费用留空。

研究室的考试与通用出愿信息引用所属专攻；额外考核、联系内诺或追加材料在研究室特殊说明中维护。变更所属专攻信息会同步更新该专攻下研究室的展示和之后的导出。

首次升级时将同一专攻、同一研究室名称的旧老师归组；未填研究室名称的老师暂归为「老师姓名研究室」，可重命名或调整归属。已有老师关注标记继续保留，不自动等同于研究室「想考」。升级事务在 `workspace_data_backups` 表保存原工作区 JSON 与修订号，升级失败时整体回滚；旧页面保存时遗漏研究室集合或老师关联，不会清空已有研究室及想考状态。

## 教授联络、日程与准备进度

修考之路新增「教授联络看板」和「时间线与日程」，当前栏目保存在 URL 查询参数中。研究室卡片与老师卡片显示联络阶段；看板可拖动卡片或使用状态下拉框，按未联系、已发首封、已回复、已约面试、已拿内诺、已结束 / 暂停分列。研究室可指定主要联系老师，看板与对比采用该老师；尚未指定时显示第一位老师，联络记录仍分别归属每位老师。

老师详情的「联络与草稿」或研究室卡片中的同名入口，可以保存计划首次联系日期、首封发送日期、面试约定、内诺日期、下次跟进、回复要点、日文第一封信草稿与备注。模板中的占位内容需要手动替换；复制草稿后由用户在邮件客户端发送。选择已发首封或内诺时仅对空白日期预填日本当天，可再调整。提交保存前的表单不写入工作区。

研究室详情新增「材料与待办」。每项可记录类型、0–100 的准备进度、截止日期和备注；支持勾选完成、编辑与移除、添加常用材料或按行导入专攻所需材料。常用清单包括研究计划书、推荐信、志望理由书、语言成绩、成绩单和毕业 / 在读证明，需按实际募集要求调整，重复项目不重复加入。每个研究室最多 200 项。

修考之路右侧按全部想考目标汇总材料完成比例、已建清单覆盖率、同名材料平均进度和未完成待办，并展示近期节点。其他待办不计入材料进度；没有建立材料清单的目标明确标记，不算作已完成。材料进度采用已建材料项的平均百分比，完成数量以 100% 为准。

时间线 / 甘特图汇总专攻的出愿窗口、所选考试年份的笔试 / 面试 / 结果日期、所有老师的计划联络 / 首封 / 跟进 / 面试 / 内诺、研究室待办截止日期。支持按起始月份显示 3、6、12 个月，点击节点查看来源；倒计时按日本时间刷新，提示 30 天内节点及逾期的未完成待办 / 联络计划。含年份的 YYYY-MM-DD、YYYY/M/D、YYYY年M月D日可识别，考试可使用完整日期范围；常规月份、未知日期等保留原文，不推测具体日期。

重叠提示区分同期出愿窗口和考试 / 教授面试同日安排。同一专攻共享的同一场考试去重；同日提示不等于时段冲突，需结合具体时间和地点确认。可导出当前时间范围的 `.ics` 日历，共享考试去重，保留研究室说明；未完成的未来节点附带提前一天提醒，出愿窗口另附截止前一天提醒，最后一天的倒计时显示「今天截止」。页面内提醒仅在工作台打开时展示，后台提醒由导入后的系统日历提供。

Excel 对比新增主要联系老师、联系状态、首封日期、教授面试、跟进与回复要点；额外的「材料与待办」表导出逐项进度、截止日期和备注，不包含邮件草稿正文。旧页面遗漏这些扩展字段时服务端保留原值，编辑研究室或老师基本资料也不会清空；删除 / 调整主要老师归属时取消失效的主要联系关联。

## 本地运行与存储

浏览器只作为工作台界面。本地 Node.js 服务只监听 `127.0.0.1`，SQLite 保存业务数据，原始文件复制到独立工作区的真实文件夹。工作区默认位于 `~/Documents/JapanGradWorkspace`，可通过 `JAPANGRAD_WORKSPACE` 修改。

大学支持 QS 排名、榜单年份、所在地和国立 / 公立 / 国公立 / 私立类型。地域采用两级下拉：先选择北海道、东北、关东、中部、近畿、中国、四国、九州、冲绳之一，再选择对应都道府县，共覆盖 47 个。都道府县支持中文和日文搜索；更换或清空地域会清空不匹配的都道府县。城市 / 详细所在地仍可自由填写。旧所在地原文保留；能明确识别的中文、日文都道府县名称会在编辑时预选对应地域和都道府县，已主动清空的选择不再自动回填。清单、详情和对比同步展示，大学搜索也支持都道府县的中日文名称。旧类型和无法识别的旧地域原值保留，编辑时可重新选择。

国立、公立、国公立的入学金默认 282,000 日元（仅第一年一次），年度学费默认 535,800 日元，可按学校实际情况修改；私立费用手动填写。总费用另外包含每月房租 / 寮费、每月生活费（不含房租）；首年预算为入学金 + 年度学费 + 12 ×（月租 + 月生活费），两年预算只收一次入学金，其余按两年计算。费用支持零元和留空；存在空项时显示已知费用小计和待补充项，不将未知费用当零。恢复默认学费只影响入学金、年度学费，保留生活预算。旧大学缺少学费字段时按类型显示默认值，已保存的自定义金额或主动留空不会被覆盖。

大学资料可记录寮申请状态（待确认 / 可申请 / 不可申请）、申请官网和资格 / 住宿备注。此状态不会自动修改房租预算。

新增或编辑大学时支持上传、预览、更换和移除校徽（PNG、JPG、WebP，最大 3 MB），保存大学后生效。原图片保存在工作区的 `university-logos/`，SQLite 保存文件标识。图片按真实内容识别类型；取消编辑保留原大学校徽。更换或移除后原图片仍保留在工作区，完整备份时一并复制。

大学详情集中展示基础资料、寮信息、研究科 / 专攻 / 老师 / 心仪老师数量、研究领域、择校笔记和总预算；清单、详情与对比统一展示校徽，横向对比包含寮信息、住宿生活费与总预算。

支持 PDF、DOC、DOCX、MD、TXT，按年份归档。募集要项与过去问采用独立的卡片清单，点击卡片进入资料详情，支持个人备注；可直接从专攻读取原文、定位初步字段并核对 Agent 草稿。PDF 通过浏览器自带阅读器打开，MD/TXT 显示原始文本，DOC/DOCX 下载后用本机应用打开。过去问的答案必须关联同专攻、同年份的具体试题。

募集要项、过去问、老师论文统一通过「新增」按钮打开上传弹窗，可拖拽单个文件或点击选择。每次仅接受一个文件，批量拖入会提示重新选择；选中后显示文件名、大小，可更换或移除，标题自动使用文件名且不会覆盖手动填写的标题。点击保存才上传原文件，取消不会新增资料。支持上述五种格式，单个文件最多 50 MB；答案上传也复用同一选择界面并保留试题 / 年份关联。

专攻页面在考试表格上方独立展示「出愿信息」：出愿开始 / 截止时间段和所需材料。可点击「编辑出愿信息」维护，时间支持具体日期或每年的常规时段，材料按行填写并展示为清单；两端为标准日期时校验截止不早于开始。信息作为专攻的通用资料保存，编辑专攻或考试记录时保留，旧页面遗漏这些字段时也不会清空已有值。

专攻详情的「历年考试信息」采用对比表格，列为考试年份、考试科目、笔试时间、面试时间、结果发布时间、备注及操作；按年份倒序显示，同一年可记录多个批次。备注直接展示该年份的出愿时间、所需材料或其他特殊变更，来源链接和原考试时间也放在备注栏。支持单条新增、编辑、删除，时间可填写具体日期、时段或待公布。旧记录的原考试时间完整保留，可在编辑时整理到对应时间栏，未填写的新栏显示待填写。

「批量录入」支持逐行填写、按起止年份生成多行、从表格粘贴制表符分列的数据（可带表头）。每批最多 50 行，空白行忽略；相同年份和批次重复时提示处理，不覆盖已有记录，生成年份时跳过已有的未分批次年份。批量通过校验后使用一次工作区保存请求，任一行错误时整批不写入。记录保存在工作区数据库内，编辑专攻不覆盖考试记录；旧页面保存时缺少的新时间栏也会保留原值，主动清空则按用户修改保存。

批量表格也支持填写每年的备注。粘贴带表头数据时根据列名识别备注；无表头则依次为年份、科目、笔试、面试、结果发布时间、批次、备注，兼容此前第六列为批次的数据。

老师独立详情页包含资料、论文库、邮件往来三个 Tab。论文支持作者、会议/期刊、阅读笔记、预览和下载；邮件采用复制粘贴，支持收发方向、日期、下一步行动与跟进日期。

首次打开空工作区时会尝试导入同一浏览器地址下的旧 `japangrad-university-explorer-v1` 数据，保留原浏览器数据及 `-before-v2` 备份。正式数据以本地 SQLite 为准，其他浏览器也可打开同一工作区。

## 开发

需要 Node.js 24 和 pnpm。仓库根目录：

```sh
pnpm dev:japangrad
```

另一个终端进入 `apps/web-antd`：

```sh
../../node_modules/.bin/vite --host 127.0.0.1 --port 5666 --strictPort
```

打开 `http://127.0.0.1:5666/japan-grad`。Vite 将 `/api/japangrad` 代理至本地服务 5667 端口。

## 构建和启动

```sh
pnpm build:japangrad
pnpm start:japangrad
```

生产工作台由同一个本地服务提供，地址为 `http://127.0.0.1:5667/japan-grad`。PDF 直接从本地服务返回给浏览器阅读，不再加载自制阅读器、PDF 解析库或在线 CDN，并已移除模板统计脚本。

## 打包

提供经官方 SHA256 校验的 Node.js 24 macOS arm64 运行时目录，执行：

```sh
NODE_RUNTIME_DIR=/path/to/node-v24.x-darwin-arm64 pnpm package:japangrad
```

产物位于工作区 `releases/JapanGrad-macOS-arm64`。软件内含运行时和静态页面，双击 `启动 JapanGrad.command` 打开浏览器，无需安装开发环境。详见 `local-server/USER_GUIDE.md`。
