# JUAI 1.0 设计系统

状态：阶段 2 规范与代表性原型。继承现有 Logo、深蓝品牌和 palette.ts；保留 design/REDESIGN.md 历史，覆盖其中旧橙绿品牌规则。

## 设计判断

JUAI 是申请者长期使用的学术工作空间。第一眼先识别「我在看谁 / 当前选择的招生范围 / 下一步能做什么」，第二层才读要求与来源。采用编辑式的信息编排：身份主区、少量并列内容区、弱化资料来源和历史。每个字段不单独成卡。不使用营销大图、装饰渐变、虚假统计或全页缩放。

## Token 单一来源

`palette.ts` 是色彩/主题与 Ant Design 的既有来源，不建立第二份色板。`design-system/tokens.css` 通过 --jg-* 映射语义色，并管理 --juai-* 的字号、间距、半径、容器和控件。所有原型使用 `.juai-design` 或对应基础组件限定范围，逐页推广，旧页面不被全局强制重排。

| 用途 | 规范 |
| --- | --- |
| 背景/表面/文字/次文/边界 | 复用 --jg-bg / surface / text / secondary / muted / line |
| 品牌/交互/未知/失败 | accent-text、accent、muted、error；状态同时使用文字，不能只靠颜色 |
| 正文 | 项目现有无衬线 --jg-font，13px / 1.65；辅助 11–12px；不把整页缩到 10px |
| 页面标题 | 28px / 1.25 / 600，主身份 28–32px；中文标题以无衬线为主 |
| 分区标题 / 关键数字 | 16px / 600；日期 22px，语言分数 22px，等宽数字 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px；卡片 24px，手机 20px |
| 圆角 | 控件 6px；分区 10px；身份面板 12px；不重复多层包边 |
| 宽度 | 详情最大 1200px；档案/设置 1040–1080px；文件工作区按实际任务扩展 |
| 栅格 | 标题与主操作同一行；要求 2 栏；研究室介绍:成员=1.6:1；手机≤720px 单栏 |
| 控件 | 桌面32px，手机关键操作至少40px；focus-visible 2px；保存中禁重复提交 |

## 基础组件（已在阶段 2 实现，验收见 PHASE2_ACCEPTANCE）

- PageHeading：所属路径、实体标题、描述及一个主要操作区域；可选 meta。长名字可换行，操作不覆盖标题。
- Section：内容主题聚合，不是字段容器；有标题、可选副标题、右侧操作与主内容。
- DateMarker：按原文展示日期。只在严格 YYYY-MM-DD 且日历合法时使用语义 time；自由文字原样保留，空值显示未确认。
- FileList：真实 API 的文件标题、格式、大小/年份、预览与下载；删除编辑上传使用现有 DocumentArchive 的完整流程，原型不另造上传器。
- EmptyState：缺失内容 + 必要的单个动作；未知值不显示 0，不伪造进度。
- ResearchLabCollection / ResearchLabTeachers / UniversityLogo：保留已有真实卡片与编辑实现，统一外层空间和标题，不复制第二套实体数据。

## 交互状态

默认阅读，点击编辑才开 Modal/Drawer；草稿与已存对象分离；取消丢弃草稿；成功等待 API 返回；失败保留内容并显示可操作错误。删除保留已有明确影响范围确认。加载、空结果、接口失败分别呈现，失败不伪装空集合。

弹窗通过现有 ConfigProvider 继承主题，不使用 html zoom/transform 影响浮层定位。内容限制视口高度，窄屏单列。隐藏入口只由导航配置或展示条件处理，不移除实现。

## 代表页的主次

个人：身份/院校/专业主区 → 两项申请目标 → 教育/语言并列 → 兴趣与可选备注；头像仅真实图片或姓名缩写。

专攻：大学/研究科路径与专业身份 → 明确考试记录选择和范围边界 → 两个日期 → 科目/材料/语言/内诺要求 → 文件/过去问并列 → 研究室。旧通用资料不冠以批次专属，解析历史折叠访问。

研究室：方向与官网主区 → 介绍和成员构成非对称布局 → 教师。招生只提供专攻入口，不复制内容。缺少人数显示暂无数据而非装饰图表。原有材料/待办/日程原型期间通过「原版与申请工具」可达。
