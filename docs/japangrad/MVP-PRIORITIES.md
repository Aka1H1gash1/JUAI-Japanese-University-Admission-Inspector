# JapanGrad MVP 完善建议

基于当前实现：已支持大学 → 研究科 → 专攻 → 老师、横向对比、资料原文件、过去问与答案、论文笔记、邮件往来，以及大学总预算、寮申请与校徽。以下是建议顺序，尚未实现。

MVP 的下一阶段目标：为一个「专攻 + 入学年度 / 批次」建立申请目标，让用户随时知道是否符合资格、下一步要做什么、何时完成，以及结果如何。

| 优先级 | 功能 | 最小可用范围 | 完成判断 |
| --- | --- | --- | --- |
| P0 | 备份与恢复 | 一键打包数据库、原文件、校徽；恢复前先保留当前工作区；校验备份完整性 | 在空目录恢复备份，大学、预算、校徽、资料、论文和邮件都可读取 |
| P0 | 申请目标与进度 | 每个专攻按入学年度 / 批次建立目标；状态为考虑中、准备中、已提交、结果已出、已放弃；独立记录是否已联系教授 | 同一专攻的不同年度互不覆盖，能看到目标的下一步行动 |
| P0 | 截止日期与待办 | 记录出愿开始 / 截止、考试、联系教授和寮申请日期；首页集中显示最近 7 / 30 天与已逾期待办 | 用户打开工作台即可知道今天、近期需要处理什么 |
| P1 | 出愿要求与材料清单 | 手动记录语言 / 英语要求、考试科目、出愿方式；材料如研究计划书、推荐信、成绩单关联文件并标记准备状态 | 能判断申请资格与缺少材料，条目附官方链接 / 资料年份和备注 |
| P1 | 择校决策与筛选 | 优先级、匹配程度、目标 / 备选分类；按预算、地域、寮、专业筛选；比较申请要求 | 可以从候选清单收敛出实际申请目标 |
| P1 | 数据导出与撤销删除 | 导出择校与申请清单；数据库记录的回收站 / 恢复入口 | 误删可恢复，关键清单可在其他工具中使用 |

建议先完成 P0 的三项。它们共同支持从整理资料、准备申请到提交后跟进的日常使用。

后续可按实际使用反馈增加其他费用明细（检定料、押金 / 礼金、保险、机票、奖学金减免）、自定义预算月数和预算版本；目前两年估算明确采用固定月租与生活费，并不自动推测寮申请结果或租房变化。

现有邮件已能记录下一步行动与跟进日期，适合接入统一待办；新增待办时应复用这些信息，减少重复填写。当前募集要项自动提取处于关闭状态，出愿要求先允许手动整理并关联原文件。
