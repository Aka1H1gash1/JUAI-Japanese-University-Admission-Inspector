# JUAI MVP 下一阶段优先级

已支持大学 / 研究室管理、总预算、教授联络看板、通用材料与日程、自选 Excel 导出，以及按年度 / 选拔批次独立管理申请、募集要项原文读取 / 初步定位 / 核对采纳、Agent 任务包与本地 MCP 接入。

| 优先级 | 下一步 | 最小可用范围 |
| --- | --- | --- |
| P0 | 一键备份与恢复 | 打包完整 SQLite、原文件与校徽；恢复前备份当前资料并校验完整性 |
| P0 | 数据库记录回收站 | 恢复误删大学 / 研究室及关联记录；已有文件 .trash 不等同于实体记录恢复 |
| P1 | 个人条件与资格核对 | 记录学历、语言成绩与有效期，对照已确认的本轮资格条款，保留判断依据和待确认项 |
| P1 | 共用材料与文件版本 | 把成绩单、语言成绩、研究计划书成品关联到各轮清单，区分共用与学校专用版本 |
| P1 | 按申请轮次对比 / 导出 | 在现有研究室通用对比与 Excel 导出基础上，允许明确选择入学轮次的要求和准备状态 |
| P1 | 官方资料修订提示 | 维护官方来源地址与版本，检测变化并提示重新核对，不自动替换人工确认内容 |
| P2 | 可选 OCR / 模型执行器 | 以同一草稿格式接入独立 OCR、用户模型 API 或本地模型；现有 Agent 可读取 PDF 页面图像 |
| P2 | 更完整预算 | 检定料、租房初期费、保险、交通与奖学金减免，支持预算月份与版本 |

本地解析与 Agent 分析都先产生草稿，再通过核对界面采纳。当前本地定位不判断选拔类别、资格或复杂表格；模型理解由用户连接的 Agent 执行。开发下一步应以真实资料的使用反馈确定范围。
