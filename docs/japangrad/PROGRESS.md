# JapanGrad 开发进度

当前交付：基于 Vue Vben Admin `apps/web-antd` 的择校前端原型。

## 已实现

- 初始大学清单为空，由用户手动添加；支持搜索、排序与 2–4 所大学横向对比。
- 四级资料层级：大学 → 研究科 → 专攻 → 老师。各级支持新增、编辑、确认删除和空状态。
- 专攻归属对应研究科，老师归属对应专攻；删除上级时一并删除下属记录。
- 老师资料包含姓名、职称、研究方向、研究室名称、联系邮箱、个人备注。
- 老师个人主页、研究室主页独立填写和展示。
- 职称下拉选项：助教、讲师、副教授、教授。
- 心仪老师标记、筛选、老师资料抽屉和研究关键词搜索。
- 当前浏览器本地保存、页面刷新恢复、独立路由和移动端布局。
- 旧版老师资料迁移到所属研究科的“未分类专攻”，保留原始备份、资料与心仪标记。

## 当前范围

数据使用浏览器 localStorage。当前进度没有包含 Spring Boot、SQLite、Electron 打包、正式 Workspace、申请管理、材料、任务或自动收集大学数据。

仓库中的 [完整 PRD](./PRD.md) 包含后续产品规划；本文件描述当前已交付的原型范围，界面与层级以本文件为准。

## 代码入口

- `apps/web-antd/src/views/japan-grad/`：页面、表单、对比、老师资料与本地数据模型。
- `apps/web-antd/src/router/routes/core.ts`：原型路由。
- `apps/web-antd/src/preferences.ts`：默认首页。
- `scripts/japangrad-smoke.mjs`：独立浏览器流程验证。

- 验证心仪标记、编辑、搜索、刷新数据保留、删除确认与上下级数据隔离。
