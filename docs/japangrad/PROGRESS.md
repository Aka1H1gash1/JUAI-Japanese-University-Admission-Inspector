# JapanGrad 开发进度

当前交付为本地浏览器工作台，基于 Vue Vben Admin 的 `apps/web-antd`、Node.js 本地服务和 SQLite。资料默认保存在 `~/Documents/JapanGradWorkspace`，软件包与用户资料独立。

## 已实现

- 已移除申请轮次页面和操作接口；资料分析直接关联专攻。旧资料有明确日期 / 清单时迁入关联研究室，旧分析结果继续供核对。
- 时间线日程可手动新增、直接编辑、移除 / 隐藏和恢复，支持首次联系、内诺、出愿时间段、各阶段考试与结果、具体起止时间及完成状态；同步图表、提醒、日历和自选 Excel 时间规划属性。
- 募集要项分析：异步隔离解析 PDF / DOCX / MD / TXT，按标题与明确日期定位初步草稿；对照原文逐项采纳、替换确认、来源 hash / 专攻 / 修订校验；核对后可更新专攻要求、考试记录和研究室材料清单。
- Agent 任务包导出与单个结果 JSON 导入；本地 STDIO MCP 查询授权专攻、读取分页文字 / PDF 图像并回传草稿，连接令牌仅创建时显示并可撤销。
- 范围：本地初步定位不判断资格和选拔类别；扫描页由支持图片的外部 Agent 分析，未内置独立 OCR、云端模型 API 或自动邮件发送。

- 大学 → 研究科 → 专攻 → 研究室 → 老师的资料管理，整卡进入详情及顶部返回上一级。
- 大学校徽、类型、QS 排名与年份、9 个地域 / 47 个都道府县联动选择。
- 入学金、年度学费、月房租与生活费预算，年度 / 首年 / 两年开销与费用缺项说明，寮申请资料。
- 独立研究室资料、研究方向、官网与考试 / 出愿特殊要求，老师可在同一专攻内调整研究室归属。
- 修考之路直接搜索、按大学筛选、批量勾选或全选研究室加入想考清单，2–6 个目标横向对比。
- 教授联络状态、拖动 / 下拉看板、主要老师、第一封信草稿、回复要点、面试约定与跟进日期。
- 修考时间线 / 甘特图、关键日期倒计时、同日安排 / 同期出愿提示、日历 .ics 导出。
- 每个研究室的材料 / 待办与百分比进度，修考之路右侧汇总材料准备和近期节点。
- 自定义 Excel 导出：先勾选研究室，再选择属性和考试年份；提供分组选择、快捷方案与预览。固定大学 / 研究室识别列，默认仅一张表，按需另附只含所选属性的考试、材料与待办明细及说明。选中费用输入列时合计可重算，仅选合计时输出数值快照，费用缺项留空。
- 语言要求：专攻通用要求与研究室单独要求，研究室留空时继承专攻；可对比、单列导出，兼容旧数据与旧页面保存。
- 通用出愿时间 / 材料独立展示，历年考试按表格对比科目与各阶段时间、备注，并支持批量录入。
- 募集要项、过去问、关联答案、老师论文的单文件拖拽 / 选择上传，保存原文件；PDF / 文本阅读与 Word 下载。
- 老师论文库、邮件记录与心仪标记，独立详情路由和栏目状态。
- 浅色 / 深色 / 跟随系统主题、桌面侧边栏与手机导航、加载和连接错误反馈。
- 旧浏览器资料迁入本地工作区；研究室升级事务保留老师身份与文件关联，并备份原工作区数据。
- macOS arm64 本地软件打包入口，内含 Node.js 运行时。

## 代码入口

- `apps/web-antd/src/views/japan-grad/`：页面、组件与本地数据模型。
- `apps/web-antd/src/router/routes/core.ts`：工作台路由。
- `local-server/`：SQLite、本地文件服务、数据校验与升级。
- `scripts/package-japangrad.mjs`：macOS arm64 打包。
- `scripts/japangrad-*.mjs`：已有自动化检查与设计审查脚本。
