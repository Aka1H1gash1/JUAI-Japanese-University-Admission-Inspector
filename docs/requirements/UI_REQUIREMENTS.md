# JUAI 全局 UI/UX 设计重构

## 1. 重构目标

当前 JUAI 前端存在严重的后台管理系统设计倾向，页面大量使用表格、表单、纵向排列的全宽容器，缺少视觉层级与合理的信息组织。

JUAI 的定位是面向日本大学院申请者的一站式考学工作空间，而非传统后台信息管理系统。

本次任务需要从产品设计和用户体验层面重构前端，而不是简单修改颜色、圆角、阴影或字体。

## 2. 技术约束

- 继续使用现有 Vue 3、Vben Admin 及 Ant Design Vue 技术体系。
- 不重新创建项目，不随意更换 UI 框架。
- 保留现有业务逻辑、API、数据结构及功能。
- 在现有组件基础上建立 JUAI 独立的设计系统。
- 不允许为了美化界面而使用虚假数据替代真实数据。

## 3. 整体设计方向

参考 Linear、Notion、Vercel、Raycast 等现代化软件的设计理念。

设计关键词：

- 现代化 SaaS
- 学术感
- 日系极简
- 清晰的信息层级
- 紧凑但不拥挤
- 克制的视觉装饰
- 内容优先

保留 JUAI 原有的品牌 Logo 和深蓝色品牌基调，但重新规划页面布局与组件视觉规范。

不要直接照搬参考产品。

## 4. 禁止的设计方式

- 不要直接将数据库字段映射为表格或表单。
- 不要默认让所有详情页面处于编辑状态。
- 不要将每个字段都放进独立的卡片。
- 不要让所有模块都占满整行并机械地纵向排列。
- 不要将长篇文字塞进表格单元格。
- 不要滥用分割线、边框、阴影和大圆角。
- 不要使用大量无意义的说明文字。
- 不要为了增加设计感而滥用渐变、玻璃拟态和动画。
- 不要简单地通过增加留白实现所谓的高级感。
- 不要把同一份数据在多个区域重复展示。

## 5. 建立全局设计系统

统一管理以下内容：

- 品牌色、背景色、文字色、边框色。
- 标题、正文、辅助文字、数字的字体层级。
- 间距规范。
- 圆角规范。
- 按钮及交互状态。
- 输入框、选择器、弹窗。
- 页面标题区。
- 信息分组组件。
- 日期展示组件。
- 文件列表组件。
- 研究室与大学卡片。
- 空状态、加载状态和错误状态。

优先使用 CSS Variables 或 Design Tokens 集中管理。

建议采用 4px / 8px 间距体系。

正文使用现代无衬线字体，避免大面积使用传统宋体风格。品牌标题可以适当保留现有学术风格。

## 6. 页面布局规范

根据页面功能选择布局，而不是让所有页面使用同一套模板。

### 列表页面

适用于大学清单、研究室清单和教授联络记录。

支持卡片与紧凑列表等适当的展示方式，合理使用搜索、筛选及排序。

### 详情页面

适用于大学、专攻、研究室详情。

采用页面标题、核心信息、内容分区的结构。

根据内容使用双栏、三栏或非对称 Grid 布局。

重要信息应优先展示，次要信息降低视觉权重。

### 工作台页面

适用于修考之路、教授联络、申请材料管理。

使用左右分栏、任务清单、内容面板等适合实际操作的布局。

### 设置页面

采用居中的适度宽度布局，不应无限横向拉伸。

普通详情页面可以将最大内容宽度设置在 1200–1440px 左右，设置类页面可以根据内容进一步收窄。

以上宽度是建议值，不是必须机械执行的固定值。

在较窄的屏幕上自动调整为单列布局，避免横向溢出。

## 7. 阅读模式与编辑模式分离

所有信息详情页面优先使用阅读模式。

阅读模式应采用普通文字、信息分组、标签和适当的数据可视化。

用户点击编辑之后，再使用弹窗、抽屉或局部表单进行修改。

尤其需要重构：

- 个人信息。
- 大学详情。
- 专攻招生信息。
- 研究室详情。
- 教师个人信息。

## 8. 重点页面重构

### 个人信息

设计为一体化个人档案页面。

上方展示个人身份、头像、院校及专业。

中间展示申请目标、教育背景。

语言成绩使用紧凑的成绩展示组件。

研究兴趣采用标签或简洁文字展示。

点击编辑后才进入表单。

### 专攻详情

上方展示专攻名称和所属大学。

招生信息采用结构化阅读布局，不使用大面积表格。

考试日期、面试日期等重要时间采用独立日期展示组件。

考试科目、语言要求、出愿材料及内诺要求采用合理的多栏信息布局。

文件和过去问左右并列。

最下方展示研究室。

不同招生批次通过选择器切换，不要重复展示大段同类信息。

### 研究室详情

上方展示研究室名称、研究方向及官网。

中间展示研究室介绍及成员构成。

成员构成可以采用简洁的比例条或环形图。

最下方展示教师。

不要展示重复的募集要项解析结果。

### 修考之路

设计成独立的申请工作台，而不是普通信息详情页。

同时展示申请目标、时间节点、研究室信息、专攻信息和材料准备进度。

材料清单与文件操作采用左右分栏。

### 教授联络

采用双栏工作区。

左侧为申请目标及联络进展，右侧为邮件记录和 AI 辅助功能。

避免重复展示完整历史信息。

## 9. 执行方式

第一步：审查现有前端页面、公共组件、全局样式及布局结构，定位造成当前视觉问题的原因。

第二步：建立统一的设计规范及可复用组件。

第三步：优先重构个人信息、专攻详情、研究室详情三个代表性页面。

第四步：使用浏览器实际渲染页面并截图，检查真实视觉效果，而不是仅根据源代码判断。

重点检查：

- 信息层级是否清晰。
- 页面是否存在过度拉伸。
- 是否存在无意义的空白。
- 字体大小与对比度是否合理。
- 是否存在重复卡片、重复边框。
- 长文本是否正常换行。
- 不同屏幕分辨率是否正常显示。
- 是否保留了原有功能。

第五步：以重构后的代表性页面为标准，统一其他页面。

第六步：完成功能测试、构建及服务器部署。

最终目标不是一个换了主题的 Vben Admin 后台，而是一个拥有独立产品设计语言的 JUAI 考学工作平台。
