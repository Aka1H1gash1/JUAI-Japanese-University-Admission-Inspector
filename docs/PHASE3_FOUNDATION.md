# 阶段 3：基础数据、兼容迁移与公共 API

2026-11-15。用户授权继续第三阶段。沿用 `refactor/juai-1.0`，没有发布产品 1.0，也没有部署服务器。

## 已实现

- 复用原 819 条大学目录。新增可持久化的 catalogId/schoolCode；手动选择及唯一明确的新增名称可关联目录；中/日/英/别名参与匹配。目录下拉展示现有校徽，全部大学校徽入口优先稳定标识，个人修改不写入公共目录。
- 后端验证已知学校的重复关联；新增同名记录拒绝。已有旧记录不会被强行改名或覆盖；旧客户端遗漏新标识仍保留。AI create_only 匹配与新增实体使用同一目录：仅唯一明确的名字/别名关联，其他情况保留人工核对流程，不猜测。
- 独立招生批次持久化：可空入学年度、批次、考试类别、范围、六项招生要求、来源和备注；内诺 required / optional / unknown。旧考试年份不自动变成入学年份，不跨批次补缺项。现有专攻原型可新增、选择、编辑、删除，真实 API 保存并支持版本冲突检测。
- 研究室成员人数持久化：日本/外国/中国均可空；中国≤外国，非负整数；可靠数据齐全时生成比例条，总人数与其他外国人数由后端计算。旧外国学生说明保留在原记录，不推算人数。
- 动态语言记录支持任意考试名称、成绩和日期，以及新增、编辑、删除。旧 language 字符串原样保留、继续可读可编辑，未强行解析成可能错误的考试记录。旧客户端不传 languageRecords 时保留已保存结构化记录；版本冲突拒绝覆盖。
- 普通个人文件直接进入原 document_records / content-store / 阅读与下载体系，不需要专攻；无第二套文件存储。文件管理增加上传、下载、删除和上传时间，显示服务端计算的空间信息。
- 文件可关联同专攻招生批次。删除前列出批次引用，仍被引用返回 409；解除引用后可删除。新引用使用外键，不跨专攻或跨用户。申请目标、邮件等更广泛引用在阶段 5 随对应业务接入，未冒充全部业务引用已完成。
- 平台配额来自当前用户服务端配置，并在原上传路径校验。纯本地默认不限额，可用 JAPANGRAD_STORAGE_QUOTA_BYTES 配置；不伪造本地有限配额或百分比。空间按用户工作区磁盘文件统计，可恢复区仍占空间。
- 私有平台：默认登录到工作区，安全的业务 next 路径可恢复；旧无邮箱账号仍可登录工作区并自愿绑定，不删除账号。邮箱换绑必须同时验证当前及新邮箱，复用 10 分钟/60 秒/5 次等限制和 HMAC 存储；历史未绑定账号为密码+新邮箱验证。密码修改后端要求再次确认，既有字母数字规则保留，并校验更新时会话密码状态。

## API

均复用 `/api/japangrad`，平台请求继承当前用户可信上下文；没有客户端指定用户 ID 的新入口。

| 路径 | 操作 / 兼容 |
| --- | --- |
| /catalog | GET 原静态目录的同源后端数据，不建立公共目录写 API |
| /foundation/majors/:id/batches | GET 列表 / POST 新批次；新增可选 documentIds 仅接受同专攻文件 |
| /foundation/majors/:id/batches/:batchId | GET / PUT / DELETE；修改删除要求 version；PUT 可更新 documentIds |
| /foundation/labs/:id/members | GET / PUT，version CAS；nullable 日本/外国/中国人数，返回 total / otherForeign |
| /settings | 原 GET / PUT 扩展 profile.languageRecords；旧字段及旧版本协议保留 |
| /storage | GET {quota,used,remaining}；quota=null 表示本地未设上限 |
| /documents | 原上传与索引扩展 workspace 所有者，ownerId=workspace、kind=other；普通文件不要求专攻 |
| /documents/:id/references | GET 当前招生批次引用；原 DELETE 遇到引用返回 409 和影响范围 |

私有平台 `/api/auth/code` 新增 change_old/change_new，用途与用户 ID/邮箱绑定；`/api/auth/email` 换绑要求 oldChallengeId/oldCode + challengeId/code，新旧校验成功后同一事务消费与更新。`/api/auth/password` 要求 confirmPassword，密码更新及会话撤销沿用原能力。
