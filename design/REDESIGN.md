# JapanGrad 前端重设计

## 设计判断

日本大学院申请资料工作台，面向长期整理学校、考试、资料和导师信息的个人用户。采用清晰、紧凑的产品界面，使用现有 Vue 3、Ant Design Vue 和工作区数据模型。

模式：保留品牌与内容的重设计。`DESIGN_VARIANCE: 4`，`MOTION_INTENSITY: 3`，`VISUAL_DENSITY: 6`。

## 修改前审查

- 品牌：JapanGrad、择校笔记、书本标记；主色为 `#b65335`，文字为深绿色，底色偏绿。
- 字体：正文使用 Avenir Next / 苹方，主标题使用宋体、Georgia；大标题与小号辅助文字反差过大。
- 导航：大学清单 → 大学 → 研究科 → 专攻 → 老师。保持所有路由、主导航标签、字段名称和字段顺序。
- 功能：整张卡片导航、对比与心仪按钮、预算、校徽、出愿信息、考试表和批量录入、单文件拖拽上传、论文和邮件。
- 问题：多种绿色和橙色散落在 CSS 中；弱对比的小字号较多；间距、圆角和分组规则不一致；长页面缺少上下文导航；弹窗与页面之间缺乏统一的主题策略。
- 当前为本地工作台，页面不对外搜索收录。保留已有页面路径和描述元信息。

## 设计实施

- 建立语义色彩变量，采用中性色底色、清晰层级和品牌橙色强调。错误、连接状态仅使用必要的语义色。
- 统一无衬线排版与数字对齐，增加表单标签、辅助信息和数据表文字的可读性。
- 桌面增加工作区导航和已有大学的快捷入口；手机使用可关闭导航，内容保持单列。
- 页面内减少重复英文栏目标签，保留实际标题与功能信息。
- 容器圆角 12px，控件 8px，小标签 6px；可点击区域提供明确的悬停、按下、聚焦状态。
- 浅色与深色使用同一套变量；弹窗、抽屉与浮层共享主题。默认跟随系统，可手动选择。
- 保留 JapanGrad 品牌标记。业务图标统一使用项目已安装的 Lucide 图标库，不额外引入运行时依赖。
- 老师使用姓名缩写作为身份标记，不添加虚构照片。
- 所有统计来自实际工作区记录。测试数据仅存在于独立临时工作区。
- 仅使用状态反馈所需的短过渡，支持减少动态效果。

## Taste Skill 的适用范围

应用本次明确要求的审查、排版、配色、交互状态、可访问性、主题一致性和重设计规则。该技能注明密集产品界面与数据表不属于其主要范围，因此采用既有 Ant Design Vue 和实际业务表格规范。

不为资料工作台添加营销页的大图、装饰照片、滚动叙事、品牌墙或虚构内容。现有用户校徽属于实际视觉资产，继续保留。字体沿用系统已有字体，保持本地离线使用。

## 验证记录

- Vite 构建和 Vue 类型检查通过。
- 大学 / 研究科 / 专攻 / 老师的新增、编辑、跳转、对比、心仪、预算、校徽、删除与旧数据迁移回归通过。
- 单文件拖拽上传、五种文件格式、原文件阅读 / 下载、答案关联、论文与邮件回归通过。
- 出愿信息、考试表备注、按年份生成、粘贴录入、整批保存、取消、并发版本校验和重启恢复检查通过。
- 五种页面在浅色 / 深色、1440px 桌面和 390px 手机检查通过，无页面横向溢出；考试表允许在自己的滚动区域内横向查看。
- 手动主题切换、刷新保留选择、跟随系统、手机导航关闭和路径切换检查通过。
- 本地服务异常展示、重试恢复、加载骨架和工作区位置窗口检查通过。
- 已修复 Select 内部可聚焦输入的读屏名称、展开状态与悬空引用；原组件的选择、键盘和数据绑定行为保留。
- 对实际渲染的主按钮、次按钮悬停、选中标签及占位文字检查：浅色最低 4.68:1，深色最低 4.84:1，均达到 AA 4.5:1。
- 减少动态效果偏好同时应用于自定义样式和 Ant Design 原生浮层。

Lighthouse 13.5.0，本地临时测试资料，桌面预设：

| 页面 | 性能 | 可访问性 | 最佳实践 |
| --- | --- | --- | --- |
| 大学清单 | 99 | 100 | 100 |
| 专攻详情 | 未重复测量性能 | 100 | 100 |

大学清单实测：LCP 0.5 s，TBT 0 ms，CLS 0。这些结果来自本机测试环境，不代表其他设备或网络环境的性能保证，也不将 TBT 等同于真实用户 INP。

## 适用检查

项目保持单一组件体系，未新增运行时依赖；已安装的 Lucide 使用本地组件，图标不依赖在线 CDN。品牌标记保留原图形。自有界面文案移除重复英文微标签和长破折号，用户原文中的名称、排名和标点不改写。

营销页的 hero 摄影、品牌墙、滚动叙事、SEO 迁移、RSC 和 GSAP 等检查对本地资料工作台不适用。真实的考试表与材料清单按业务需要保留，并提供独立的手机滚动区域。
