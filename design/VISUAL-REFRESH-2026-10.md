# JUAI 工作台视觉更新

## 设计判断与现状审查

这是个人日本大学院申请工作台，采用视觉更新模式，保留页面层级、地址、主导航、表单顺序和交互。使用 design-taste-frontend 中适合产品展示面的字体、配色、层次与响应式原则；营销页 Hero 图片、滚动叙事、内容删减和禁止数据表等要求不适用于日常资料工作台。

原界面使用 Avenir Next / 系统中文字体、灰白底色、赭色强调色、12px 卡片与 8px 控件。大学清单、详情、研究室、老师、修考之路共用样式。主要问题是导航与内容的背景接近，搜索与资料卡的层次雷同，页面标题和预算重点不足。保留整卡进入、独立对比勾选、返回上一级、主题切换、键盘焦点和原始资料展示。此应用为本地工作区，无营销 SEO 迁移。

## 方向

- DESIGN_VARIANCE 6：在保持信息架构的基础上，用有色页头、概览条和卡片分区建立层次。
- MOTION_INTENSITY 3：仅为操作提供悬停、按下反馈；遵循减少动态效果偏好。
- VISUAL_DENSITY 5：日常工作台密度，保留数据表、完整记录及必要说明。
- 单一现有设计系统 Ant Design Vue，无新增依赖或外部字体请求。
- 靛蓝强调色 #4355b9，配蓝灰中性色；浅色与深色分别定义语义变量，状态中的错误与成功保留语义色。
- 字体延用本机 Avenir Next、PingFang SC 与中文系统后备，调整字重、数字和标题层级。
- 卡片 16px、控件 8px、标签 6px；卡片内部小区块可用 8px。

## 内容与界面

首页标题区、真实大学 / 专攻 / 研究室 / 想考数量概览、大学卡片的校徽区和首年预算区。预算复用既有计算逻辑，缺失金额注明已知费用和预算缺项。研究室和教授卡片、大学详情费用、修考之路页签、待办栏、联络看板与上传窗口采用统一视觉语言。无装饰性假数据、额外营销文案或仿造截图。

手机下标题操作换行、概览两列、大学卡片单列。深色模式保持相同层级，侧栏不反转为独立主题。已有来源照片和校徽保持原样，产品界面不增加装饰图片。

## 交付检查范围

执行 Vue 类型检查、Vite 构建、diff 检查和页面截图目视审查。未新增或运行自动化测试、Lighthouse 测试或业务回归套件。无数据库结构或 API 改动。
