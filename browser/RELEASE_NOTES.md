# JUAI v1.3.0

这一版统一了淡色界面与列表布局，新增周／月日历，并将核心业务资料迁入关系表。升级前自动备份完整工作区，保留既有文件、邮件、批注和历史记录。

## 新界面

- 使用低饱和度的冰蓝、薄荷绿及少量浅紫、浅黄，统一主要页面的标题字体。
- 申请总览以日历为主区、待办为侧栏，下方展示研究室阶段轴和可自选的缺项提醒。
- 日历支持一周详细视图与自然月摘要视图，可翻页、展开节点并手动加入待办。
- 大学清单、修考之路和特殊项目改用横向列表及细分隔线，保留搜索、筛选、对比、编辑和导出入口。

## 数据库升级

- 升级为 schema 14，大学、研究科、专攻、研究室、老师、考试、待办、日程、联络经历、文件与邮件使用关系表。
- 增加外键、事务和版本条件写入；想考开关和单条材料／待办采用增量保存。
- 旧 JSON 保留为只读迁移存档；迁移前自动创建完整备份，校验失败会回滚。
- 升级后重复启动、历史文件与批注保留、并发编辑均已有回归测试。

## 资料安全

- 新增「设置 → 本地工作区」：一键备份完整工作区，运行中也能备份。删除大学、研究科、专攻、研究室或老师前，确认框会提示先备份。
- 「完全退出 JUAI」集中在同一页，并说明关闭浏览器不会停止后台服务。
- 启动失败时会弹窗说明原因和日志位置，不再双击后没有反应。
- JUAI 改用固定地址打开，阅读笔记草稿等浏览器内的设置在重启后会保留。

## 修复

- 勾选材料完成后再取消，会恢复勾选前的进度，不再变成 0%。这个进度保存在工作区里。
- 智能导入的待办与时间线上已有的出愿、考试节点同一天时，时间线只显示一个；往年已经过去的日期不再被导入成逾期待办。
- 通过微信或当面得到老师回复时，可以手动把联络阶段改为「已回复」，之后不会被邮件记录改回。
- 关闭填了一半的资料表单前会先确认，不再直接丢失输入。
- 出愿时间写成文字时，表单会提示它不会进入时间线和提醒。
- 网址解析不再允许选择重启后已经没有 API Key 的连接；配置 AI 时在新标签页打开，已填的内容会保留。

## 改进

- 特殊入学项目移到主导航；关注或准备申请的项目，其日期会出现在申请总览、时间线和日历导出里。
- 某个专攻只有往年考试记录时，时间线和申请总览会提醒补充新一年记录。
- 统一了「网址解析」等功能名称；「新增研究室」改为「选择想考研究室」；「想考」用心形、「心仪老师」用星形区分。
- 网址解析和募集要项提取在开始前会说明哪些内容会发送给模型服务。
- Excel 导出会记住上次选择的属性和年份。

## 使用

### Windows

1. 下载 `JUAI-1.3.0-windows-x64.zip` 并完整解压。
2. 双击文件夹中的 `JUAI.exe`。
3. 不要单独移动 EXE；运行时需要同文件夹内的 `runtime`、`web` 和 `local-server`。

### macOS

1. 下载与芯片匹配的 ZIP 并解压。
2. 将 `JUAI.app` 拖入「应用程序」或直接双击。
3. 当前便携包尚未公证；首次可能需要在 Finder 中右键点击「打开」。

从旧版本升级时，直接用新版替换软件文件夹即可。资料保存在 `Documents/JapanGradWorkspace`，不随软件文件夹移动或删除。

## 手机访问

在电脑版「设置 → 手机访问」中开启，确保电脑与手机位于同一 Wi-Fi，再在手机打开生成的临时链接。手机访问期间电脑必须保持开机且 JUAI 保持运行。
