# 分级解析与只新增导入（v3）实施记录

2026-11-09；核心目标版本1.4.1，服务器目标版本0.7.1。业务schema16、平台schema3、连接器协议1不变。发布结果以私有仓库专项验收记录为准。

普通网址任务固定显式层级与create_only策略。前端四类入口中老师／研究室必须明确子类型；上下文改变类型后解除原父级。特殊入学项目继续独立。

保存分为服务端核对计划和确认提交。已有对象只能发送ID引用；新对象采用有证据字段或经过绑定到具体值与草稿版本的用户确认。普通旧任务必须显式升级核对策略，升级不会调用模型。旧覆盖载荷、强制重复创建、无效归属、过期预览及层级矛盾均被拦截。

仓库只INSERT新对象、新考试与新文件，不经全量replace/upsert或考试日程同步。事务内重读任务、工作区和资源，重建计划核对指纹。任务完成、导入历史、对象及资源同事务提交；同任务重试返回原结果，不产生额外历史。没有业务新增时可正常只关联，界面明确显示无新增。

考试同年同批次跳过，不补空。PDF按用户工作区、所有者、类型、资料年度、SHA256判重；源文件变化可取消资源后保存其余合法内容。文件准备使用独立UUID路径、尝试清单与原子清单替换，失败只清理本次未引用文件，启动时检查过期清单。文件准备计入备份忙碌检查。摘要以任务中的独立来源型记录保存明确所有者，按真实所有者读取；相同摘要只关联已保存记录。范围不明的摘要保留在草稿，不能归档为全校要求。

研究室负责人默认不勾选；已有研究室联系人与想考状态不写入。新老师建立初始联络记录。外国人学生状态扩展真实字段白名单并核验来源，缺信息的新档案默认unknown，不从姓名或照片推断。

前端显示已有对象只读、新对象完整候选字段、服务器预览与资源所有者；保存失败保留编辑内容，刷新归属后可重建计划。已生成计划的选择会在返回任务时恢复，过期计划仍须重新核对。

## 明确边界

学校真实组织结构缺少专攻或研究室时，不创建占位对象；需补充真实关系或新建明确任务。别名、改组和历史重复档案需要人工核对，不自动合并或改挂。大学／研究科PDF原件仅留任务来源，正式文件库仍只支持专攻或老师。摘要范围尚不明确时必须取消该资源，不能用通用确认框绕过。无法识别或没有可靠证据的资料保持待核对。

本次没有重写历史业务档案；正常人工编辑、独立上传募集要项、材料待办、特殊项目、导出及登录边界继续沿用各自流程。原有未跟踪目录`local-server/vue-vben-admin/`保留。
